# SMITE 2 Real-Time Ping Overlay

Минималистичный внутриигровой HUD-оверлей для отображения актуального пинга в SMITE 2 в реальном времени.
Скрипт динамически считывает IP-адрес игрового сервера напрямую из логов движка Unreal Engine 5, измеряет точную задержку подключения в обход ICMP-блокировок и выводит информацию на экран поверх игры.

## 🚀 Основные возможности

1. Полная автоматизация: Скрипт сам определяет начало игры и мгновенно выводит текущий пинг и IP сервера.
2. Умный трекинг состояния: При завершении матча или выходе в главное меню оверлей автоматически сбрасывает данные и переходит в режим ожидания (Ждем матч...).
3. Абсолютная сквозная прозрачность: Окно полностью прозрачно для курсора мыши. Оно не перехватывает клики, не мешает целиться, стрелять и управлять игровым интерфейсом.
4. Идеальное расположение: HUD статично закреплен в левом нижнем углу экрана (аккуратно над панелью задач), не отвлекая от игрового процесса.
5. Цветовая индикация: Текст динамически меняет цвет в зависимости от качества соединения (зеленый — отличный, желтый — средний, красный — высокий пинг).
6. Удобное управление: Оверлей работает без консольного окна, но добавляет иконку в системный трей (возле часов), через которую приложение можно закрыть в один клик.

## 💾 Быстрый запуск (Без установки Python)

Если вы не хотите устанавливать Python и собирать проект самостоятельно, вы можете использовать уже скомпилированную автономную версию:

1. Склонируйте репозиторий или скачайте его архивом.
2. Перейдите в папку **`/application`** в корне проекта.
3. Запустите файл **`smite_ping.exe`**.

Оверлей сразу появится в левом нижнем углу экрана и свернется в системный трей возле часов.

## ⚠️ Важно

По умолчанию готовый `.exe` настроен на стандартный путь логов `C:\Users\Administrator\AppData\Local\SMITE2Alpha\Saved\Logs`.
Если ваше имя пользователя в Windows отличается от **`Administrator`**, этот готовый файл не сможет найти логи. В таком случае вам необходимо изменить имя пользователя в исходном коде `smite_ping.py` и скомпилировать свой собственный файл по инструкции ниже.

## 🛠️ Системные требования и зависимости

Для работы скрипта требуются операционная система Windows и установленный Python 3.x.
Перед запуском необходимо установить библиотеку для интеграции иконки в системный трей Windows:
python -m pip install pystray pillow

## ⚙️ Настройка путей

По умолчанию в скрипте прописан стандартный путь к логам игры для профиля администратора:
LOGS_DIR = "C:\Users\Administrator\AppData\Local\SMITE2Alpha\Saved\Logs"
Если ваше имя пользователя в Windows отличается от Administrator, просто откройте исходный код скрипта в любом текстовом редакторе и укажите ваш корректный путь к папке логов SMITE 2 в переменной LOGS_DIR.

## 📦 Сборка в автономный .exe файл

Чтобы использовать оверлей как полноценную утилиту без необходимости каждый раз запускать Python, скомпилируйте его в один исполняемый файл с помощью PyInstaller.
1. Установите компилятор:
python -m pip install pyinstaller
2. Выполните сборку:
python -m PyInstaller --noconsole --onefile smite_ping.py
Команда --noconsole скроет черное окно консоли, а --onefile упакует весь код в один файл
3. Заберите готовый файл smite_ping.exe из созданной папки dist.

📝 Как закрыть оверлей

Так как у окна нет стандартных рамок Windows, закрытие реализовано через область уведомлений:
1. Найдите значок приложения в системном трее возле часов (зеленые круговые стрелки 🔁).
2. Нажмите на иконку правой кнопкой мыши.
3. Выберите пункт «Выход» для полного завершения процесса.

*Дисклеймер: Этот проект является фанатской утилитой. Он не внедряется в процессы игры, не изменяет файлы памяти (не является читом) и использует исключительно официальные текстовые логи, генерируемые движком Unreal Engine 5, поэтому абсолютно безопасен для использования и не вызывает блокировок со стороны античита (Easy Anti-Cheat).*
